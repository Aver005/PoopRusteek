# План релиза: шлюз, новый UI, секреты

Цель: сделать Pooprusteek удобным агрегатором многих подписок и ключей, с чистым интерфейсом и единым хранением секретов. Идеи — в `ideas-inbox.md`, исходные отчёты — в `research-2026-11/` и `ideas/`.

## Решения владельца (2026-11-06)

| Вопрос | Решение |
|---|---|
| Главная | Карточка и сессии сверху, ввод всегда внизу |
| Подписки | Официальный CLI. Прямые токены — для всех, кроме Claude, только ручным включением с предупреждением |
| CLI-аккаунт | Сначала режим модели: инструменты и подтверждения наши. Режим агента — следующий релиз |
| Конфиг | Два слоя: `~/.pooprusteek` и `.pooprusteek/` в проекте, поиск вверх до корня git |
| Чужой проектный конфиг | Может добавить аккаунт с `base_url`, но первый запрос подтверждается, а секрет привязан к хосту |
| Секреты | Автоперенос в системное хранилище с проверкой чтением. Нет хранилища — секрет остаётся на месте с предупреждением |
| Зависимости | `toml_edit` разрешён, чтобы сохранение не стирало комментарии |
| Язык UI | Английский. Перевод в этот релиз не входит |
| Git | Локальная ветка `feature/gateway-release`. В конце разрешён push только этой ветки, `develop` и релизы не трогаем |

## Решения ведущего по умолчанию

Владелец их не выбирал, можно изменить.

- Старый `[[providers]]` мигрируется один раз с копией файла, дальше не пишется.
- Fallback в потоке — только до первого ушедшего чанка.
- Учёт токенов — агрегаты через `atomic_write` раз в 30 с.
- Порог «заранее» включён только при свежем снимке лимитов. Оценка даёт лишь предупреждение.
- Диалект Anthropic в `/serve` — отдельным этапом после интеграции.
- Экспорта секретов нет, на другой машине ключ вводится заново.
- На Windows конфиг в `%APPDATA%`, данные и кэш в `%LOCALAPPDATA%`, с миграцией.
- Enter во время хода ставит сообщение в очередь.
- В первом релизе нет `spread`, рекурсии маршрутов и активных проб.

## Ограничения

- Подписка Claude: только настоящий CLI, токены не читаем, `/api/oauth/usage` не зовём, раздача через `/serve` наружу выключена. См. раздел Authentication and credential use в правилах Claude Code.
- CLI в режиме модели не должен выполнять свои инструменты: иначе нарушается инвариант 11. Проверяется экспериментом до заморозки контрактов.
- MSRV 1.91. wasmtime берём 36.x, а не 50.
- Шифрование не защищает от процесса того же пользователя. Обещать защиту от агента с `bash` нельзя.
