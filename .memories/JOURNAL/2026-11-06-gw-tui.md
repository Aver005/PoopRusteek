Ветка `t3/02e41989`. Основа: `.docs/research-2026-11/07-ui-critique-round-2.md` (макеты §6, правки §2–§3, шов §5),

## Что сделано

**Экран `/accounts`** (`/providers` — алиас; `/routes` и `/roles` — тот же экран с фокусом на блоке).
- Код: `src/app/gateway_view.rs` (состояние, кэш снимка, связка с `App`), `gateway_view/{rows,edits,wizard,forms}.rs`
  (чистая логика), `src/app/keys/accounts.rs` (клавиши), `src/tui/render/accounts.rs` (рисование).
- Список: имя (`label` — как назвал пользователь), тип `API/CLI/WEB`, статус знаком и словом, окна лимитов с возрастом и
  источником (`live · 5s`, оценка `~` и штриховая шкала, `stale`), модели (избранные со звездой), заметка («rate limit hit
  2 times»). Ниже: цепочки маршрутов, роли, последнее решение (`Decision::explain()` как есть + причины пропуска с
  «back in 2m 10s»). `Enter` — подробности, `h` — история решений.
- Ранжирование: `K/J` в списке двигает аккаунт (`MoveAccount`) и выстраивает за порядком списка главный маршрут;
  `Tab` → маршруты: `K/J` двигает шаг, `x` убирает, `←/→` выбирает маршрут; `Tab` → роли: `←/→` меняет маршрут роли;
  `r` — войти в главный маршрут или выйти из него; `Space` — вкл/выкл; `e` — ограничения и избранные модели;
  `d` — удалить (с `y/n`); `p` — закрепить чат; `u` — пересобрать недоступный аккаунт.
- Мастер (`Modal::AccountWizard`): тип → имя → адрес/модель → секрет. Типы: API-ключ, Claude Code, OpenCode, прямой
  токен. Для CLI два пути: «своя папка входа» (по умолчанию, `~/.pooprusteek/accounts/<id>`, показывается команда входа) и
  «общий вход» с предупреждением. Прямой токен — только за `DIRECT_TOKEN_WARNING` и выбором второго пункта (по умолчанию
  «Cancel»); для Claude пункта нет, а адрес Anthropic с токеном отклоняет `validate()`. Ключ API идёт в системное
  хранилище (`set_verified` на `spawn_blocking`), в `Account.secret` лежит только ссылка `keyring:…`.
  Id аккаунта выводится из имени (`claude-max`, при совпадении `-2`), имя — `label`; логин из токенов не определяется.
- Новый аккаунт становится последним шагом главного маршрута; маршрута нет — создаётся `main` и роль `main`.
- Шлюз выключен: экран объясняет и по `Enter` включает его (`enable_gateway`): старые `[[providers]]`/DeepSeek →
  `[[accounts]]`, маршрут `main`, `enabled = true`, шлюз пересобирается.
- `/pin <аккаунт[/модель]>`, `/pin off`: чат на `Binding::Fixed`, маршрут не меняется; подвал показывает `pinned <имя>`.
- `/usage`: таблица за 24 часа по аккаунтам (вызовы, сбои, fallback, токены, доля кэша, пометка оценки).
- Шов: на `FallbackTaken` (источник — чат или суб-агент) в историю встаёт `ui_only`-строка со статусом `SEAM`:
  `── switched claude-max → opencode-go: rate limit, back in 2m 10s`. В контекст модели не идёт.
- Подвал: короткий индикатор `● claude-max +2` (только при ≥ 2 аккаунтов, приоритет сегмента 2, уходит первым при
  нехватке места). Главная: строка `accounts  ● claude-max 52% · ◔ opencode-go 2m 10s`.

**Запись.** Читаем `Gateway::snapshot()`, пишем `Gateway::apply_edit()`. Сохранение: `ConfigPersist` (был `None` во
всех сборках) теперь шлёт полный новый `GatewayConfig` событием `AppEvent::GatewayPersist`; приложение кладёт его в
`Config` и вызывает `config::save` (очередь SECRETS). Ошибка записи показана на экране и в статусе.
`ConfigChanged`: открытая беседа без провайдера берёт нового, а с другим режимом инструментов — со следующего хода
(`adopt_provider_after_edit`); закреплённые чаты не трогаются. Недоступный аккаунт пересобирается при любой правке
(`sync_runtimes` больше не держит рантайм с упавшим адаптером) или клавишей `u`.

**`[[providers]]` больше не пишутся.** `Config.providers` — `skip_serializing_if = load::providers_not_written`.
Снимок «до» и текущий строятся одной и той же сериализацией, поэтому diff их не видит, а старые записи в файле не
теряются и читаются. Тест `providers_are_read_but_never_written_and_never_lost`. Старые экран, мастер и
`provider_rows` удалены; `/providers add <быстрая форма>` открывает новый мастер на шаге подтверждения.

**Недоделки SECRETS.**
- `/secrets set <имя>` без значения открывает модалку с маской (`HiddenInput`: `Debug` без значения, обнуление при
  `Drop`, вставка идёт мимо поля ввода). Запись — `secrets::ops::set` на `spawn_blocking`. Строка с значением в
  командной строке по-прежнему работает и не попадает в историю (`is_sensitive_input`).
- Диалог проектного слоя (`Modal::Trust`): при запуске (`App::new`), после перечитывания конфига и при изменении файла;
  показывает путь и `held_back` (адреса и что меняется). Фокус по умолчанию — отказ; `Enter` на отказе, `Esc`, `n`
  оставляют слой заблокированным, `y` ничего не делает. «Trust» пишет решение так же, как `pooprusteek trust`
  (`config::trust_project`) и перечитывает конфиг.
- Перезагрузка конфига — событием: `ResetProvider` и `/cd` (`CommandResult::ReloadConfig`) читают конфиг на
  `spawn_blocking` и присылают `ConfigReloaded`; ожидание очереди записи (до 2 с) больше не на цикле событий.
  Файл проектного слоя проверяется тиком раз в 3 с (`ProjectConfigStamp`, чтение метаданных вне цикла).

**Правки экрана (§2–§3 отчёта).**
1. Блок инструмента (`widgets/tool_block.rs`): статус по итогу команды — `[exit code N]`/`[terminated by a signal]` в конце
   вывода `bash`/`powershell` делают блок красным `✗ bash  exit 101`; показывается хвост вывода (3 строки, у упавшей — до 8)
   и «… N earlier lines». Остальные инструменты — начало, как раньше.
2. Главная: курсор на сессиях (`↓`, `↑`, `Enter`, `Esc`; печать и непустое поле имеют приоритет), строка аккаунтов,
   подсказки не дублируются (убрана `tips_line`).
3. Док: потолок строк зависит от высоты окна (4 / 6 / 8), `+N more agents` — своей строкой, не на строке очереди.
4. Окно подтверждения: заголовок `Allow bash?`, одна схема (`Enter` разрешить, `Esc` отказать, `A` сменить область, `↑↓`
   прокрутка), `ANYTHING` → `any command`/`any call`, опасные слова вынесены в строку `risky: …`.
5. Выделение строки: маркер `▌` + заливка `selection`, текст не перекрашивается: `/accounts`, `/mcp`, `/models`,
   `/themes`, автодополнение.
Быстрые: заголовки markdown без решёток и цветом, курсор «пишу» `▍` в конце идущего ответа, подпись под сообщением
выровнена по тексту (`612 tok`), `?` в фильтре → знак ввода, пустое состояние поиска в 80 колонках и висящая `·`,
`ON` + `●` в `/mcp` слиты в один столбец, затемнение окна под модалкой не пропускает ячейки с цветом по умолчанию (D1).

## Решения по ходу

- **Статические поля из `Config`.** Снимок не несёт адрес, папку входа и заявленные пределы. Подробности (`Enter`) и
  форма `e` берут их из `Config` приложения (то же, что движок получил при сборке и что `GatewayPersist` держит в
  синхроне); всё живое — из снимка. Так не менялся контракт `AccountView`. Если интегратор захочет строго «только
  снимок», нужны поля `base_url/home/limits` в `AccountView`.
- **Скрытые знаки.** Новые знаки (`▌ ◔ ★ ▒ ▍`, маска) — в `glyphs.rs`; `←` и `↻` вне списка безопасных, поэтому в
  подсказках слова `Left/Right`.
- **«Подсказка `y` в диалоге доверия»** не принимает ничего намеренно: подтвердить можно только осознанно.
- **Команда входа** (`claude auth login`, `opencode auth login`) показана по документации CLI; живой вход не проверялся
  (токенов нет).
- **Часовой пояс.** «Last decision» печатает локальное время: на снимках оно зависит от пояса машины.

## Проверки

- `cargo clippy --bin pooprusteek -- -D warnings`, `cargo fmt --check`, `cargo test --bin pooprusteek` (1950+ тестов, 0 упавших): хук пройден на обоих коммитах.
- Отказ от диалога доверия помнится по хэшу файла до его изменения (`ProjectWatch::denied`), чтобы `/reset` не спрашивал снова.
- Мутации (на каждую упали нужные тесты, правки откачены): `failed: msg.tool_error` без кода выхода → 2 теста
  `tool_block`; `TrustDialog::new` с фокусом «Trust» → 3 теста доверия; `HiddenInput::mask` отдаёт значение →
  `a_typed_secret_never_reaches_the_input_the_history_or_the_screen`.
- Главный сценарий: `two_subscriptions_of_one_kind_are_added_with_a_handful_of_keys` — настоящие клавиши мастера дважды,
  две подписки Claude со своими папками входа, маршрут создан, ошибок конфига нет; в мастере тот же результат проверяет
  `two_subscriptions_of_one_kind_get_their_own_login_folders` (`validate()` чист).
- Снимки: `.dev/research/ui/after-3` — аккаунты (две подписки Claude в списке), мастер (4 шага), подтверждение
  проекта, скрытый ввод, `/usage`, шов, главная с курсором и строкой аккаунтов; 80×24 и 120×40, темы default/nord/paper.
