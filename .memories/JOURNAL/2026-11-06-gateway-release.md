## Волна 1

- DEPS (DeepSeek) закончил ход на «жду хук», без итога и пока его `git commit` ещё шёл. Статус «completed» у агента не значит, что задача сделана: проверять коммиты в worktree.
- Первый тест PoW от DEPS был пустым: сравнение двух `solve_pow` проходит при `None == None`. Возвращён на доработку с эталоном и отрицательной проверкой.

- GW-0 слит в релизную ветку (`e3668f5`) после ревью. Три находки major закрыл ведущий, остаток — в журнале GW-0.
- PoW: у DEPS был выдуманный challenge и вывод «решения нет». Живой ход на wasmtime 36 принят сервером (`79277`), теперь это фикстура теста.

- Ревью GW-ENGINE нашло critical: смена аккаунта удаляла серверную сессию пользователя. Решение: автоматическая смена цели сессии не удаляет никогда. Остальные находки возвращены автору движка. Слияние — после правок.

- Ревью SECRETS: 1 critical (копия открытых ключей при совпадении папок конфига и данных), 9 major. Решения: автоудаления секретов нет, откат оставляет настройки без ключей, проектный слой без подтверждения не меняет адрес запросов, добавлена команда `pooprusteek trust`. Возвращено автору.

- При слиянии SECRETS сборка упала: `.gitignore` (`secrets.*`) скрыл `src/cli/secrets.rs` и `src/commands/defs/secrets.rs`. У автора всё собиралось из-за файлов на диске, хук этого не видит. Правило: перед приёмкой дорожки проверять чистую копию ветки, в итоговой проверке обязательна сборка из свежего клона.

- Подключение SECRETS↔ENGINE влито (`4d20d91`): шлюз включается из конфига, сквозной тест двух аккаунтов с разными ключами проходит.

## Вопросы и риски

- `config::queue::two_quick_saves_keep_their_order` упал 1 раз за 5 полных прогонов, под нагрузкой других сборок. В одиночку 9/9, 48 параллельных запусков 48/48. Причина не найдена, тест теперь печатает ошибки записи. Также `update::swap` однажды падал у автора SECRETS. Если повторится — смотреть `atomic_write` на Windows: отказ при переименовании (занятый файл) потерял бы сохранение конфига.

- На диске C свободно 2 ГБ. Временные файлы сборки держать на D, иначе возможны сбои, похожие на ошибки кода.
- Сборка только из PowerShell с MSVC 14.50 из `H:\VS Build Tools`. В Git Bash `link.exe` — это GNU link.
- Pre-commit хук из Git Bash не линкует тесты без `CARGO_TARGET_X86_64_PC_WINDOWS_MSVC_LINKER`.
