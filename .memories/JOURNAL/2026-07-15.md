# Part 2 — same-day defect batch (all 7 items fixed)

Executed the audit's suggested batch 1 in verified increments (build+test
green after the A+B clusters, full `fmt` + `clippy -D warnings` + test gate
at the end): **436 passed** (+2 new tests), clippy 0, fmt clean.

1. **win_job for MCP stdio** — `win_job` re-exported (`pub(crate)`) from
   `tools/background/mod.rs` (same pattern as the `force_kill_pid`
   re-export); `StdioTransport::new` binds every stdio child via
   `assign_child_handle`. A force-close can no longer orphan MCP servers.
2. **`'d'` remove-server off the loop** — mirrors toggle/reconnect:
   `tokio::spawn` + `McpOperationDone`. Stale `selected` after the list
   shrinks is safe: render indexes via `visible_indices`, keys use `.get`.
3. **`tick_is_visual` unified** — the predicate now checks the *focused*
   conversation; the `Tick` arm calls the same method instead of its
   diverged 3-clause copy. Doc comment states the lockstep requirement.
4. **Sub-agent malformed-tool recovery** — `parse_tool_calls_with_errors` +
   the main loop's bounded retry; `MAX_MALFORMED_TOOL_RETRIES` hoisted from
   a fn-body const to a `pub(crate)` module const and
   `malformed_tool_feedback` made `pub(crate)` so both loops share them;
   exhausted retries return an explicit `Err`. `parse_tool_calls` demoted to
   `#[cfg(test)]` (clippy's dead-code lint caught its last production caller
   disappearing — the audit's own theme, live). New test:
   `malformed_tool_call_is_retried_not_swallowed`.
5. **Semantic poison tolerance** — new `lock_inner()` helper
   (`PoisonError::into_inner`) on every blocking-path lock (13 sites, incl.
   the multi-line one in `spawn_init`); bounded event-loop paths unchanged
   (poison = busy, degrade). New test:
   `poisoned_lock_recovers_instead_of_panicking`. NOTE: embedding still runs
   *under* the lock — that's a hold-time concern covered by the bounded
   degrade paths, deliberately deferred (fixing it means restructuring
   embedder ownership; structure batch).
6. **401 stats order** — `requests` counted before the auth gate so
   `errors > requests` is impossible.
7. **`/export`** writes through `util::atomic_write`.

BUGS.md: all 7 entries moved to RESOLVED. STATE.md focus updated. Remaining
from the audit: dedup batches (client trio next), structure batch, owner
decisions (ACP, ServerCapabilities, reasoning_content inbound,
