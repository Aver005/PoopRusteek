Ветка `t3/6165923d`, основа `5569e94`. Источники: `.dev/research/final-review-{tui,regressions,security}.md`
(TUI целиком, regressions major-1, security M1 и M5). Каждая находка сначала сверена по коду; ложных нет,

## Что сделано

**TUI C1 — мастер не падает на длинном имени.** `AccountWizard::make_id` вернул `Result`, `expect` убраны: база
режется по границе символа под лимит id (64) с запасом на суффикс `-N`, суффикс считается так, чтобы свободный id
находился всегда. Остальные `expect` в экранах — на константах (`ROLES`, `hints`), не на вводе; `hints` переписан без `expect`.

**TUI M1 — хвост вывода и `exit N`.** Корень: `run_tool_calls` клал в `display_content` первые 200 байт.
Теперь `agent::result_display`: у `bash`/`powershell` — хвост до 6000 байт с подписью выхода, у остальных — прежняя
выжимка. Блок инструмента для команд всегда показывает конец (и при `is_error`, а именно так приходит ненулевой код),
«N earlier lines» считает строки команды. Сцена снимка собирает ленту через ту же `result_display`, а упавшая
команда в сцене — с `is_error = true`, как в приложении.

**TUI M2 — шов в свой чат.** `GatewayEvent::FallbackTaken` получил `conversation: Option<u64>`. Чат хода едет
через task-local `gateway::handle::with_chat` (ставит `run_guarded`, вложенный суб-агент остаётся в чате родителя);
задача стрима (`agent::stream::collect`) переносит его через `spawn`. Нет чата — шва нет нигде.

**TUI M3 — удаление аккаунта из маршрута.** `RemoveAccount` в движке снимает шаги аккаунта со всех маршрутов тем же
`apply_edit`; единственный шаг маршрута — отказ с названием маршрута и роли. Подтверждение (`RemoveConfirm`) называет
маршруты, закреплённые чаты и ключ в хранилище («остаётся, `/secrets rm <имя>` удалит»); хранилище по `d` не
трогается (решение владельца). Единственный шаг — вопроса нет, причина на экране.
Ограничение: единственный аккаунт единственного маршрута удалить нельзя (сначала добавить другой).

**TUI M4 + regressions major-1 — шлюз выключен или собирается.**
- `[[providers]]` пишутся точечно в файл (`config::providers_file`: добавить, убрать, поменять поле) мимо
  сериализации `Config`, поэтому «читаются, но не пишутся» и миграция остаются как были. Ключ в файл идёт ссылкой
  `keyring:…`, значение — в хранилище.
- Мастер при выключенном шлюзе: только API-аккаунт (подписки — «включите шлюз»), имя = slug; порядок: запись в
  файл → ключ в хранилище → при сбое ключа запись снимается. Сирот нет в обе стороны (тест с отказавшим хранилищем).
- Экран при `enabled = false`: список (DeepSeek + записи), `Enter` — сделать активной (`active_provider`), `a` — добавить,
  `g` + `y` — включить шлюз (с вопросом). `/models` и `/providers tools` пишут `model`/`tools` записи в файл.
- Включение шлюза подтягивает записи, которых ещё нет аккаунтами (добавлены при выключенном шлюзе); ключ — ссылкой на
  запись `account_secret_id(имя)`, значением в аккаунт не идёт.
- Включённый шлюз: до записи секрета кандидат проходит `validate()` (m1), при отказе `apply_edit` секрет удаляется.
- `Starting`/`Failed`: мастер остаётся открытым с «подождите»/причиной, секрет не пишется, `a` не открывает мастер.
  Экран при сборке показывает предупреждение шлюза и «starting» вместо «no accounts» (m2), `enable_gateway` обновляет снимок.

**TUI M5/M6 — закрепления.** `Pin { account, model, label, gateway }` вместо ярлыка. `rebuild_provider` больше не
сбрасывает закреплённый чат: `refresh_pins` пересобирает провайдера на новом шлюзе, а если аккаунта нет или он выключен —
снимает пин с заметкой в том чате и возвращает его на маршрут. Удаление закреплённого аккаунта снимает пины сразу.
`/pin` на выключенный/недоступный аккаунт отказывает (m7), экранный `p` печатает результат, а не «Pinned» всегда.
`/models` на закреплённом чате меняет модель его аккаунта (m8). Заметка о пине говорит «until you quit» (m9).

**Безопасность M1 — диалог доверия.** `TrustRequest.summary` (хосты по самой таблице, без логина в адресе, + число
аккаунтов/маршрутов/ролей). Диалог: сводка первой строкой и целиком, весь список с прокруткой (↑↓, PgUp/PgDn,
Home/End), «Trust» недоступен, пока документ не показан подряд от первой строки до последней (прыжок в конец середину
не засчитывает); по умолчанию отказ, Enter на отказе закрывает отказом. `trust_view` — один размер для кадра и клавиш.

**Безопасность M5 — ключ не в чат и не в сессию.** Ошибки `/providers add` и `/mcp add` не повторяют строку; причина
проходит `echo_safe` (позиционный токен-ключ быстрой формы, слова ≥ 6 символов у `/mcp add`, потом `redact`).
`AppState::push_system`/`push_ui_system` вычёркивают секреты (`redact`) для любой заметки — они уходят в сессию и модели.
История и так отсекает такие строки (`is_sensitive_input`).

**Minor.** `/usage`: ledger суточный (UTC-дни), настоящих 24 часов нет — окно названо честно «today and yesterday
(UTC days)». `std::fs::metadata` с цикла событий убран (m4); новый/пропавший файл проекта замечается, первый взгляд не
в счёт, смена проекта сбрасывает штамп (m5); диалог доверия, отложенный модалкой, возвращается на тике (m6);
подвал при шлюзе называет модель, что отвечает (закреплённая или по последнему выбору), без «DeepSeek» (m12);
многострочная вставка в скрытое поле отклоняется с причиной (m11); шапки трёх модулей — две строки (m13).
