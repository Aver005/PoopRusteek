## GOAL Mode Implementation

Implemented iterative goal-driven agent loop (`/goal` command):

- `/goal` toggles GOAL mode (switch on/off)
- User enters prompt → system asks for goal → both sent to agent 1
- Agent 1 finishes → evaluator agent (non-streaming, dedicated system prompt) reviews work
- Evaluator returns structured verdict: `**Status:** SUCCESS/FAILURE` + summary/issues/feedback
- On SUCCESS: show summary, cycle ends
- On FAILURE: feedback sent back to agent 1, iterates
- After 3 agent1 failures → new session swapped (fresh context)
- After 5 evaluator failures → new evaluator session
- Evaluator sessions saved with `tag: "__goal_system__"` — hidden from `/sessions` UI
- VISIBLE state in status bar (`GOAL:stage`) and landing page (`[GOAL ON]` / `[iter#N]`)
- Blocks regular input during active cycle
