# 2026-11-14 — новый вид TUI по макетам

Макеты (HTML, четыре варианта и сводный) согласованы с автором в чате; итог:
«Тихий центр» по умолчанию, «Лист» как вторая главная, правая панель из «Панели»
фиксированной ширины, шапка и выбор сессий из «Якоря снизу». Ветка
`feature/gateway-release`, коммиты по шагам, каждый шаг — три ревьюера
(DeepSeek Flash) и проверка находок по коду.

## Что сделано

1. **Каркас чата** (`1cb3915`). `layout::Regions`: шапка, колонка с полями
   `SIDE_MARGIN` 3, поле ввода в рамке (`composer::render_input_box`, подсказка
   клавиш в верхней границе только когда что-то идёт), подвал — линия-зеркало
   шапки (`footer`): модель · ctx · очередь … провайдер. Панель
   (`render/panel.rs`) — 30 колонок всегда, авто с 120, на всю высоту между
   шапкой и подвалом; секции Now / Context / Accounts / Tools, пустые
   скрываются. `Ctrl+B` (было `Ctrl+P`) и `/panel`, выбор — `[ui] panel`.
   При открытой панели дока нет, её «Now» показывает то же (с токенами и t/s).
2. **Главные** (`edebaee`). `welcome.rs` рисует главную сам: «center» и
   «sheet», `[ui] landing`, `/landing`. Курсор и цифры выбирают только
   нарисованные сессии (`welcome::visible_sessions` — один расчёт для кадра и
   клавиш). Главная больше не перерисовывается на каждом такте.
3. **`/resume`** (этот коммит). `View::Resume`: сессии текущей папки, Tab —
   все проекты, фильтр по названию, прокрутка с полосой, Enter открывает.
   `/sessions` — то же самое; старый пикер-модалка удалён вместе с
   `PickerKind::Sessions`, `PickerState::new`, `PickerItem::warn`. Строка
   сессии общая с главной (`render/session_row.rs`).

## Решения, о которых стоит знать

- Док прячется при открытой панели — на макете были оба, это повтор.
- Подвал при открытой панели не повторяет GOAL/фон/таймеры/ошибки, но
  оставляет модель, ctx и очередь: панель можно закрыть.
- Часы из подвала убраны (не было на макете); `fix_clock` удалён.
- Строка аккаунтов с лимитами на главной убрана: аккаунт — справа в подвале,
  лимиты туда — следующий шаг (пожелание автора).
- Транскрипт (вид сообщений, инструментов) не менялся: на макетах он был
  упрощён, но в согласованный список работ не входил.

## Отложено (в BUGS)

- Автодополнение в окне 40×10 на главной может лечь на шапку.
- Ответ чтения `/resume` без поколения: повторное открытие сразу после
  закрытия может на миг показать прошлый снимок (данные те же).
- Enter в `/resume` читает файл сессии на цикле событий — как и `/load`.
- Главная показывает недавние сессии всех папок, `/resume` — текущей.
