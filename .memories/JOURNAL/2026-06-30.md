## Big refactor + multi-chat features wave (same day, later session)

Goal: turn the strictly single-turn god-object into a clean multi-conversation architecture, then add
sub-agents and sidechat — and document it all. Commits `42f6164` → `391c6e4` (26 commits).

### 1. Provider seam (`42f6164`, `f783a87`)
- Extracted prompt/history assembly to `provider/prompt.rs` and SSE buffering to `provider/sse.rs`.
- Added `FakeProvider` (`provider/fake.rs`, `#[cfg(test)]`) so the agent/provider seam is testable.

### 2. God-object `App` decomposition (`245367d`…`5205be4`, `b8730ee`, `cda4d97`, `a64ded8`)
- Lifted cohesive sub-state into modules: `goal.rs`, `input.rs` (+`InputState`), `mcp_status.rs` (`McpStatus`),
  `generation.rs` (`GenerationState`). Unified `bash`/`powershell` into one shell module. Extracted TUI
  `view_model`. Split monolithic `background.rs` into submodules; extracted shell-control id parsing.

### 3. GOAL overhaul (`c0d4280`)
- Hardened the pipeline against misuse (empty prompt/goal, interrupt+new message). Pure `apply_verdict` core.

### 4. The "evaporating messages" bug (`183712e`)
- Root cause: `parent_message_id` desync forked the DeepSeek session onto an invisible branch — message showed
  in the TUI but never reached the web view / model context; interrupted streams triggered it.
- Fix: incremental `parent_message_id` persist + flush-on-error in `deepseek.rs`. See LEARNINGS + BUGS.

### 5. Conversations + provider fork (`20c90ca`)
- `LLMProvider::fork()` (fresh-session sibling); `Conversation` + `Conversations` store; `ConversationId`;
  agent events tagged with the id; per-conversation isolated session. Removed the live/parked duality.

### 6. Multi-chat features (`438e60d`, `6c04774`, `38ce06f`, `92163cb`)
- `/btw` one-shot sidechat; `/new`+`/chats` parallel sessions (Tab/Ctrl cycle); sub-agents via model `task`
  tool + `/agent`/`/agents` (foreground default, `background:true` opt-in). `multichat.rs` holds the spawn/focus
  logic; `agent/sub_agent.rs` is the headless runner.

### 7. Controllers (`4efe8cb`, `c24c7a8`, `24e6b00`, `391c6e4`) — this session
- `4efe8cb` centralized conversation state management.
- `c24c7a8` **AgentRuntime** (`app/runtime.rs`): owns `tools`/`mcp`/`event_tx`; `spawn(TurnSpec)` is the single
  agent-turn launch point (DRYs the duplicate `run_agent_loop` calls).
- `24e6b00` **system_prompt::build** (`app/system_prompt.rs`): narrowed `build_system_prompt` from a `&self`
  god-method to a free fn with explicit deps (prompts/skills/tools/mcp/workspace).
- `391c6e4` **BackgroundCounters** (`app/background_stats.rs`): grouped the 3 `running_*_count` data-clump
  fields + their refresh/shutdown/kill/prune helpers off `App`; moved MCP poll methods onto `McpStatus`.
