## Deep enrichment of `.memories` for cold-start agent onboarding

Goal: make `.memories` complete enough that an agent handed the project with zero prior context
can understand it fully by reading this folder.

### Method
Four parallel deep-reading passes over the whole `src/` tree (provider, app+TUI, agent+tools,
MCP+commands+infra), plus `.docs/` and git history. Findings synthesized into the files below.
All claims tied to `→ file:line`.
